# 实验协议与结果

归档共693次：441次基础与动态实验使用20个合工大实例及BIW-43，每实例3个种子、7种方法；252次交期实验使用20个合工大实例及包装订单，每实例3个种子、4种方法。共22个不同实例。

研究求解统一5秒、单线程、种子0/1/2。合工大实例按整批加工，单位工时乘批量并计入准备时间；交期设为最短工序链时间的1.5倍。包装组保留原始日期。动态事件发生于工序边界，停机持续所选任务工时的60%，向上取整至0.1秒。

静态跨度逐实例、逐种子除以FCFS跨度后取平均。CP-SAT的平均比值0.7526105，对应24.74%改善。图中区间按实例聚类自助抽样3000次计算。

动态全局跨度比0.8324797，平均变更17.25397道；局部跨度比0.9863687，平均变更8.52381道。局部目标为Cmax加10倍开始时刻偏移，先用60%预算，按校验结果扩大范围并使用实际剩余预算。

业务交期目标使用1000倍加权延期加跨度；业务少改动目标使用100倍开始时刻偏移加跨度。研究交期实验采用两阶段：首阶段最多80%预算降低总延期，再在已达到的延期上界内使用剩余预算压缩跨度。

BIW-43协作预算80时最优跨度1647.9秒，FCFS为2119.9秒。包装组SPT总延期42001696秒，FCFS为54516589秒，减少22.96%。合工大组交期优化平均总延期23.92594小时，FCFS为31.36892小时。
