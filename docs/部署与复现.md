# 部署与复现

## 本地部署

1. 安装Python 3.12，下载或克隆仓库。
2. 在根目录创建虚拟环境：`python -m venv .venv`。
3. Windows执行`.venv\Scripts\Activate.ps1`，Linux执行`source .venv/bin/activate`。
4. 安装依赖：`python -m pip install -r app/requirements.txt`。
5. 启动：`python start.py --port 8788`，访问`http://127.0.0.1:8788`。

首次注册建立管理员，之后注册的账号作为普通用户，由工作区管理员添加成员与角色。业务数据库位于`app/var`，前端已构建在`app/frontend/dist`。所有账号及业务数据库均在本机初始化。

## 演示操作

创建工作区 → 导入Exam01 → 设置生产开始和交期 → 配置工作日历 → 生成候选排程 → 锁定任务 → 登记设备维护 → 分析影响并重排 → 提交审核 → 由另一账号审批 → 发布 → 查看三维回放。

在三维车间切换白车身焊装单元，预算80时计算43任务排程。使用任务点击、视角旋转和时间线播放观察计划。

## 智能助手

在工作区设置填写个人Kimi密钥，或复制`.env.example`为`.env`后填写`MOONSHOT_API_KEY`。配置只在本地生效。仓库保留的是配置示例。助手支持订单和设备查询、交期评估、异常分析及排程草案。

## 华为云Linux运行

在已准备的Python 3.12环境中执行相同安装流程。前台启动命令：

```bash
python start.py --host 0.0.0.0 --port 8788
```

使用HTTPS入口时设置`JIAOQI_ALLOWED_ORIGINS`为实际域名、`JIAOQI_COOKIE_SECURE=true`，然后启动服务。端口、目录与同环境其他应用保持独立。现有开发者空间通过DevBridge连接8788端口。

## 测试与实验

```bash
python -m pytest -q app/tests
python app/scripts/复现实验.py --suite biw --workspace 999
python app/scripts/复现实验.py --suite full --seconds 5 --seeds 3 --workspace 999
```

数据库和新运行结果不会覆盖仓库归档的693次实验。原始数据、模型代码、任务安排、校验状态与指标均保存在仓库中。模型包括CP-SAT调度程序和Three.js设备几何代码；Kimi服务通过部署者的API配置调用。

## 前端修改

在Node.js 22.12+环境中执行`cd app/frontend`、`npm ci`、`npm run build`。后端API文档位于`/docs`，健康检查位于`/api/health`。

## 备份

停止服务后备份`app/var`、`runtime`和`secrets`。这些目录保存本机运行数据，与公开源码分别管理。
