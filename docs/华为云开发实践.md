# 华为云开发实践

项目使用华为云码道CodeArts代码智能体参与核心Python后端开发，具体产物覆盖认证与工作区、HFUT数据适配、调度模型、独立校验和方案接口。保存的开发记录包含128条会话事件和51个文件映射，公开摘要见`华为云开发记录.json`。

开发过程按需求与接口拆分、核心编码、国内数据适配、回归测试与部署集成展开。数据集成关注批量工时转换、候选设备与日历；计划发布关注独立校验、审核角色及版本一致性。

应用已部署至华为云AI开发者空间持久化环境，目录`/root/JiaoqiManager`、端口8788，通过DevBridge提供HTTPS页面。当前使用SQLite业务存储与Kimi模型接口。
